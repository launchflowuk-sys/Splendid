# Fonts

`sans.ttf` and `serif.ttf` are the exact font files supplied in the client
handover package (`handover/assets/fonts/`). The handover identifies them as
**DM Sans** and **DM Serif Display**, both released under the SIL Open Font
License 1.1, which permits redistribution as part of this theme.

They are registered as `SplendidSans` and `SplendidSerif` in
`assets/css/design.css` and in `theme.json`, and are served from this directory —
the site makes no external font requests.

Before launch, confirm the embedded family and style names in these files match
what the licence expects, and keep this notice with them. See
`handover/assets/FONT-NOTICES.md` for the handover's own note.
