# Splendid Double Glazing — complete WordPress handover

Prepared 9 September 2026. This package captures the approved GREEN design and all 38 implemented routes. It gives Claude Code the content, source, assets and build specification to implement the complete WordPress website. It is not an installable WordPress theme yet.

## What to give Claude Code

Extract this entire ZIP into the development workspace. Ask Claude Code to read `CLAUDE-BUILD-PROMPT.md` and carry out the task. Give it access to a local or staging WordPress installation when available. The package is self-contained for design and content; access to the ChatGPT preview is not required.

## Contents

- `CLAUDE-BUILD-PROMPT.md`: the complete implementation instruction.
- `content/SITEMAP.md` and `sitemap.csv`: every page and URL, with SEO metadata.
- `content/pages/`: all 38 page bodies in readable Markdown and HTML fragments.
- `content/pages.json`: structured route, template, copy and metadata manifest.
- `content/original-data.json`: complete products, area copy, articles, FAQs and business details.
- `content/shared-shell.html`: shared header/footer reference markup.
- `reference-source/`: original React components, exact CSS, content data and dependency references.
- `assets/`: all three original architectural WebP images, two local font files, favicon and extracted design CSS.
- `briefs/`: design fidelity, navigation, production functionality, WordPress legal drafts, business confirmations, SEO and acceptance criteria.
- `wordpress/`: staging commands and a draft-only page importer.
- `evidence/`: research sources, captured source identity, asset provenance and package verification.

## What is ready and what still needs a client answer

The complete design, sitemap and existing copy are supplied. The business phone, email, registered name, number and address have public supporting sources. A real business cannot be fully verified from a design: product availability, certification, guarantees, project photographs, review permissions, opening hours, hosting/email access and data-handling arrangements need client confirmation. Those questions are collected in one document. Claude should keep building everything that does not depend on those answers.

The existing prototype uses email drafts, not server-delivered enquiries. Its legal notices describe that prototype. The production brief replaces that behaviour and supplies WordPress-specific policy drafts, marked for final configuration and business review. Do not publish the prototype privacy notice on a site that stores or emails submitted enquiries.

The gallery images are AI-generated design illustrations, not photographs of completed Splendid installations. They can support an inspiration section with clear labelling. A real-work portfolio needs the client's own approved photographs.

The original source export deliberately excludes private deployment configuration, credentials, Git history and dependencies. It is the visual implementation reference, not a standalone framework project intended for deployment. Claude is building a WordPress theme from it.
